# Existing compiler upgrade

The current extractor, resumable normalization, geometry reconciliation, portable IDs, merge, asset resolution and MCP injector remain in place. Work is ordered by correctness and scope.

1. Remove automatic visual review from generation, regression commands and default tests. Keep one-section, one-issue manual debugging, with actual frontend capture when requested. Normal builds must not require vision credentials or a browser.
2. Audit the connected Bricks version, discovery abilities, native schemas and installed client skills. Use verified controls and structures; never guess element names or settings.
3. Preserve measured Figma properties and record source coverage. Support deterministic normalization for designs with sufficient hierarchy/layout data. Preserve unsupported design information in an explicit report rather than silently discarding it.
4. Recognize native components conservatively from names, hierarchy and design evidence. Compile verified navigation, sliders, tabs, accordions and forms with native editable children/settings. Ordinary card rows must remain flex/grid unless carousel evidence exists.
5. Add nonvisual structural, schema, component, responsive-rule and asset checks. Validate reusable fixtures and saved CasinoFX inputs without screenshots or model calls.
6. Document supported components, commands and remaining limits. Production pages remain untouched. Staging injection requires an identified staging target; frontend interaction and visual quality remain unverified until exercised there.

Source backups for orchestration and the existing visual tool are retained under `.review-work/upgrade-backup-*`. Existing generated outputs and private credentials are preserved.
